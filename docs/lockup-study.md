# AJAR 심볼·이름 조합 보정안

2026-10-28 · 시각 검토안 / 최종 선택 전

C1 독립 심볼, 전체 이름을 Outfit으로 쓰는 구조, 브랜드 정의와 컬러는 유지한다. 기존 조합의 글자 무게와 크기를 비교한다. 기준 BI 자산은 덮어쓰지 않고 아래 안을 별도로 제공한다.

| 안 | 글자 굵기 | 기존 대비 크기 | 심볼과 이름의 간격 |
| --- | --- | --- | --- |
| 00 기존 | Regular 400 | 100% | 약 45 |
| 01 작게 | Regular 400 | 75% | 28 |
| 02 얇게 | Light 300 | 85% | 28 |
| 03 작고 얇게 · 추천 | Light 300 | 75% | 28 |

수치는 동일 설계 좌표 기준이다. 모든 안의 심볼 크기는 같다. 글자의 점과 아래로 내려오는 j를 포함한 실제 윤곽의 중심을 심볼과 맞췄다.

03은 전체 글자 높이가 심볼 높이의 약 75%, 두 요소 간격은 심볼 높이의 약 32%다. 심볼이 시각적 중심을 잡고 이름은 가볍게 읽히도록 한다. 작은 크기에서 03이 가늘게 보이면 01과 다시 비교한다.

실제 SVG 렌더링으로 밝은 바탕·녹색 바탕, 큰 조합과 축소 조합을 검토했다. 사용자의 최종 선택 전이므로 기존 C1·Outfit Regular 400 기준을 승인된 새 규칙으로 바꾸지 않았다.
