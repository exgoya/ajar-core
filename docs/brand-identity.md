# AJAR Brand Identity v1.3

기준일: 2026-10-28  
상태: 핵심 정의·슬로건 승인 / C1 독립 심볼 + Outfit Light 300 전체 워드마크 선택 / 사용 규칙 v1.3

## 1. 브랜드 정의

[Brand Definition v1.2](brand-draft.md)을 따른다.

**AJAR — 언제든 열려 있는**

AJAR는 **열려 있는 상태 자체를 정체성으로 삼는 브랜드**다. 현재의 형태를 가지면서도 새로운 생각과 다음 변화가 들어올 여지를 남긴다.

‘언제든’은 그 태도가 지속된다는 뜻이다. 시작할 때도, 진행하는 동안에도, 마무리한 뒤에도 다시 생각하고 이어갈 수 있다.

‘열려 있는’은 방향과 가능성을 미리 한정하지 않는다는 뜻이다. 무엇에 열려 있는지는 AJAR가 만들어가는 일과 관계를 통해 채워진다.

- **생각의 여지:** 새로운 관점이 더해지고 기존 판단이 달라질 수 있다.
- **형태의 유연함:** 각 프로젝트는 목적에 맞는 자기 모습을 가질 수 있다.
- **이어갈 가능성:** 멈추거나 끝낸 일에도 다음 시작의 여지를 남긴다.

작은 실험과 학습 기록은 이 정체성을 실천하는 방식이다. 시도하고, 배우고, 바꾸고, 다시 이어가는 과정에서 AJAR의 열려 있음이 드러난다.

## 2. 이름과 문장

- 공식 이름: **AJAR**. 일반 문서에서는 대문자로 쓴다.
- 이름 표기: 소문자 **ajar** 네 글자 전체를 **Outfit Light 300**으로 쓴다. C1의 a는 독립 심볼이다. 심볼을 첫 글자로 끼워 넣거나 일부 글자만 바꾸지 않는다.
- 슬로건: **언제든 열려 있는** ‘가능성’ 등의 단어를 붙여 공식 슬로건을 바꾸지 않는다.
- 한 줄 소개: “열려 있는 상태 자체를 정체성으로 삼는 브랜드.”
- 기본 말투: 담백하고 명료하며 여지를 남긴다. 실제 시도와 배움을 구체적으로 설명한다.
- 예시 문장: “생각이 더해질 여지를 남깁니다.” / “멈춘 지점에서 다시 이어갑니다.”

## 3. 로고 체계 — 독립 심볼과 전체 이름

**심볼: C1의 열린 a. 이름: Outfit Light 300으로 쓴 ajar 전체.**

심볼은 정원 몸통, 열린 오른쪽 위, 하나의 연속 획과 짧은 오른쪽 세로획으로 구성한다. 워드마크는 네 글자 모두 서체의 원래 글자 형태를 사용하며 기본 커닝, 추가 자간 0으로 조판한다.

원의 균형과 둥근 끝이 유연함을 표현한다. 굵은 선은 식별성을 유지하고, 바닥보다 살짝 올라간 세로획은 오른쪽 아래의 무게를 줄인다. 심볼의 열린 부분은 그대로 유지한다.

### 제작 원형

- 설계 좌표계: 160 × 160.
- 원 중심: (75, 80), 중심선 반지름: 44.
- 열린 각도: 45°.
- 선 굵기: 10. 끝과 접점은 round.
- 원호 끝 (119, 80)에서 세로획 끝 (119, 116)으로 연결한다.
- 둥근 캡을 포함한 세로획 끝은 y=121, 원호 바닥은 y=129. 시각적 높이 차이는 8이다.
- 심볼은 path 하나, 시작 이동 하나, 닫기 없는 연속 경로다. 단일 획 원칙은 심볼에 적용한다. 전체 워드마크는 글자별 경로를 사용한다.
- 배포 파일은 여백을 포함한 viewBox를 사용한다. 다운로드한 SVG의 비율을 그대로 유지한다.

### 조합과 사용

| 자산 | 용도 |
| --- | --- |
| 워드마크 | 웹 헤더, 소개 문서, 브랜드 첫 노출의 기본 표기 |
| 심볼 | 프로필, 파비콘, 앱 아이콘, 이미 이름이 보이는 작은 영역 |
| 심볼 + 전체 워드마크 | 심볼과 이름을 충분히 띄워 나란히 쓰는 가로 조합. 제공 lockup 파일 사용 |
| 워드마크 + 슬로건 | 표지, 소개 화면, 포스터. 슬로건은 읽을 수 있는 크기의 별도 텍스트로 배치 |

- 보호 여백: 로고의 실제 윤곽에서 사방으로 선 굵기의 2배 이상을 확보한다. 크기를 바꾸면 같은 비율로 조정한다. 제공 SVG에는 이 여백이 들어 있다.
- 디지털 기본 최소 크기: 여백을 포함한 심볼 가로 24px, 워드마크 가로 120px, 가로 조합 200px. 슬로건은 별도 본문으로 12px 이상을 권장한다.
- 16px 파비콘은 별도 축소 보정 전까지 보조 용도로만 쓴다. 인쇄 최소 크기와 인쇄 색상은 실물 교정 후 정한다.
- 가로·세로 비율, 원의 열린 각도, 선 굵기, 세로획 길이, 자간은 개별적으로 바꾸지 않는다.
- 기본 로고에 그림자, 외곽선, 그라데이션을 추가하지 않는다. 열린 틈을 장식이나 다른 요소로 메우지 않는다.
- C0·C2·C3 및 이전 A·B는 탐색 기록으로 보존하며 기준 로고 자산과 구분한다.

## 4. 컬러 — Moss & lime

| 역할 | 이름 | HEX | RGB | 사용 |
| --- | --- | --- | --- | --- |
| 바탕 | Warm paper | `#F2F0E8` | 242, 240, 232 | 넓은 배경과 여백 |
| 기본 | Deep moss | `#26392D` | 38, 57, 45 | 로고, 본문, 윤곽 |
| 강조 | Open lime | `#DBEA5C` | 219, 234, 92 | 작은 강조, 선택 상태, 열린 지점 |
| 단색 보조 | Black / White | `#000000` / `#FFFFFF` | — | 단색 출력과 배경 대응 |

- 기본 화면 구성의 출발점은 바탕 70%, 녹색 25%, 라임 5%다. 정밀한 할당량이 아닌 시각적 위계 기준이다.
- 녹색 로고는 따뜻한 바탕이나 라임 바탕 위에 사용한다. 어두운 녹색 바탕에는 라임 또는 흰 로고를 사용한다.
- 라임 로고와 라임 본문은 녹색 바탕에서 사용한다. 밝은 바탕에서는 녹색을 글자·로고 색으로 쓴다.
- Deep moss / Warm paper의 대비는 약 10.79:1, Deep moss / Open lime은 약 9.34:1이다. 두 조합 모두 일반 본문 대비 4.5:1을 넘는다.
- 인쇄용 CMYK·별색은 미지정이다. 임의 변환을 공식 인쇄 기준으로 간주하지 않는다.

## 5. 서체와 편집

- 영문 브랜드 서체: **Outfit**. 로고의 전체 이름 ajar는 **Light 300**을 사용한다.
- 큰 영문 제목과 워드마크는 Light 300, 본문과 작은 라벨은 Regular 400을 사용한다.
- 네 글자를 같은 서체로 조판한 SVG를 제공한다. 벡터 파일은 폰트 설치가 필요 없다. 텍스트를 직접 입력할 때는 Outfit, weight 300, 추가 자간 0을 사용한다.
- C1은 글자 일부를 대체하는 용도가 아니라 독립 심볼이다. 처음 a를 C1로 바꾸고 jar만 서체로 쓰는 혼합 방식은 사용하지 않는다.
- 영문 브랜드 텍스트도 Outfit을 사용하며 한글 본문은 `"Apple SD Gothic Neo", "Malgun Gothic", sans-serif`를 대체 서체로 사용한다.
- 공식 Google Fonts 배포본 `Outfit-Variable.ttf`와 `Outfit-OFL.txt`를 패키지에 포함했다. 원본 폰트에는 손대지 않았으며 워드마크만 벡터 아웃라인으로 제공한다.
- 서체 원본: https://github.com/google/fonts/tree/main/ofl/outfit
- 제목 32–56px, 본문 16px / 행간 1.7, 보조 정보 12–14px를 출발점으로 사용한다.
- 한글 제목은 과도하게 좁히지 않고, 본문은 자간을 기본값으로 유지한다. 긴 설명은 짧은 문단으로 나눈다.
- 위 스택은 시스템별 대체 서체를 사용하므로 OS마다 모양이 달라질 수 있다. 한글 전용 배포 서체는 추후 선택한다.

## 6. 그래픽과 모션

- 공통 그래픽은 열린 윤곽과 가변하는 틈이다. 선 굵기를 통일하고 형태가 또렷하게 읽히도록 한다.
- 프로젝트별 그래픽은 열린 위치와 크기를 변주할 수 있다. **기준 로고 C1은 고정**한다.
- 라임은 새로운 요소가 들어오거나 연결되는 지점을 작은 면적으로 강조한다.
- 모션은 심볼의 한 획이 이어지는 흐름을 활용한다. 반복되는 장식 애니메이션보다 첫 등장이나 선택 피드백에 짧게 사용한다.
- 동작 줄이기 설정에서는 그리기 애니메이션을 생략한다.

## 7. 적용과 제공 파일

자산은 [`../brand/assets/`](../brand/assets/)에 보관한다. 같은 파일을 웹 가이드에서도 다운로드할 수 있다.

- 심볼·전체 워드마크·가로 조합: moss / lime / black / white SVG, 각 4종.
- 투명 PNG: 심볼 256·512px, 워드마크 가로 1200px, 가로 조합 1050px.
- 서체: `Outfit-Variable.ttf`, `Outfit-OFL.txt`.
- 체계 비교 보드: `ajar-identity-system.png`.
- 토큰: `ajar-tokens.css`, `ajar-tokens.json`.
- 가이드: 이 문서, `ajar-bi-overview.png`, 전체 자산 ZIP.
- 웹: https://exgoya.github.io/ajar-core/#bi-guide

SVG가 제작 원본이다. PNG는 미리보기와 일반 적용용이다. 흰색·라임 자산은 적절한 어두운 배경 위에서 사용한다.

## 8. 결정 상태와 검증

- 소유자 선택: 브랜드 정의와 슬로건, C1 독립 심볼, 전체 이름 ajar를 Outfit Light 300으로 조판하는 구조.
- 기존 대화의 녹색·라임 선호를 바탕으로 Moss & lime을 이 가이드의 기준 팔레트로 정리했다.
- 보호 여백·최소 크기·색상 비율·본문 서체는 첫 적용을 위한 v1 규칙이며 별도의 사용자 확정 발언을 뜻하지 않는다.
- 현재 사용 기준은 C1 독립 심볼과 Outfit 전체 이름이다. 심볼을 워드마크의 일부 글자 대신 사용하지 않는다.
- 남은 항목: 한글 전용 배포 서체, 인쇄 교정, 16px 전용 심볼, 상표 등록 검토가 필요한 경우의 별도 조사.
- SVG 자산을 실제 PNG로 렌더링해 심볼·워드마크, 역상·단색, 보호 여백과 축소 가독성을 검토한다. 검증 결과와 웹 배포 상태는 진행 기록에 남긴다.


## 9. 조합과 편집 보정 — BI v1.3

레퍼런스의 절제된 타이포그래피, 심볼과 이름의 역할 분리, 넓은 여백을 참고해 [보정안 03](lockup-study.md)을 반영했다. C1의 형태와 색상, 브랜드 정의는 유지한다. 타 브랜드의 심볼·서체·색상 자산을 가져와 사용하지 않는다.

- 워드마크: Outfit Light 300. 단독 표기와 조합 모두 같은 글자 윤곽을 사용한다.
- 조합 크기: 이전 조합 대비 텍스트 75%. 이름의 실제 전체 높이는 심볼 높이 H의 약 0.75H다.
- 내부 간격: 약 0.32H. 이름의 j 점과 아래 부분을 포함한 윤곽의 중심을 심볼 중심과 맞춘다.
- 본문·작은 정보는 Regular 400을 사용해 가독성을 유지한다. 로고의 굵기를 작은 크기에서 임의로 바꾸지 않고 최소 크기 이하에서는 심볼 단독을 사용한다.
- 웹 가이드는 작은 번호·라벨, 얇은 구분선, 넓은 여백으로 심볼·이름·조합을 나누어 보여준다.
- 참고: [Polestar / Stockholm Design Lab](https://www.stockholmdesignlab.se/work/polestar)의 담백한 타입 운영과 역할 분리, Airbnb의 선형 심볼과 소문자 비례. AJAR의 고유 자산으로 재구성했다.

SVG를 실제로 렌더링해 큰 조합과 축소 조합, 밝은 배경·녹색 배경을 검토했다. 기본 자산 4색, 토큰, 문서, BI 보드와 다운로드 패키지를 함께 업데이트한다.


## 10. 앱 아이콘·파비콘 패키지

`brand/assets/icons/`에 플랫폼별 에셋을 추가했다. 아이콘에는 C1 독립 심볼만 사용한다. 기본은 녹색 바탕·라임 심볼이며 밝은 바탕·녹색 심볼 대안도 제공한다.

- iOS: 1024 불투명 원본, AppIcon.appiconset, 앱 내부 SVG template imageset.
- Android: launcher 5 density, adaptive foreground/background, API 33 monochrome 및 24dp 알림 벡터.
- 웹: SVG·16/32/48 ICO·크기별 PNG·180 터치 아이콘·192/512 일반 및 maskable 아이콘·manifest.
- favicon.svg 및 16·32px PNG는 작은 크기용으로 선 굵기만 12로 보정했다. C1 경로는 그대로며 기본 앱 아이콘은 굵기 10이다.
- 자세한 적용과 검증 범위는 [아이콘 README](../brand/assets/icons/README.md)를 따른다. 실제 앱 빌드와 스토어 업로드는 별도 검증 대상이다.


## 11. 디자인 아이디어 이미지

2026-10-29, 이미지 생성 도구(built-in image_gen)로 세 가지 탐색용 이미지를 제작했다.

- 열린 윤곽: 포스터·브랜드 그래픽의 입체감과 여백.
- 종이와 틈: 종이·노트의 재질, 겹침과 작은 라임 강조.
- 모바일의 여백: 얇은 구분선과 넓은 간격의 모바일 비주얼.

원본 PNG는 모두 1536×1024이며 같은 내용의 WebP를 웹에 사용한다. 파일은 `brand/assets/ideas/`, [프롬프트 기록](../brand/assets/ideas/prompts.md), [적용 설명](design-ideas.md)에서 확인한다. 이미지는 디자인 방향을 살펴보기 위한 콘셉트이며 실제 제품·앱 구현이나 공식 로고의 변경을 뜻하지 않는다.
