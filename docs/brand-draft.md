# AJAR 브랜드 초안
상태: DRAFT / 소유자 검토 전 / 2026-10-23

**AJAR — 언제든 열려 있는 가능성**

AJAR는 부담 없이 돌아와 시작할 수 있는 지속적인 기회의 공간을 지향한다.
각 Sub Project는 독립적인 실험이며, 작은 시도와 기록을 느슨하게 연결한다.
성공의 크기나 출시 횟수보다 다시 시도할 수 있는 여지와 배운 내용을 남기는 것을 중시한다.

## 운영 가설
- 작은 범위로 시작하고, 종료 조건과 보류 조건을 먼저 정한다.
- 프로젝트는 독립 저장소에서 진행한다. core는 방향과 등록부를 연결한다.
- AI는 기획 초안을 제안하고, 소유자가 검토·수정·승인한다.
- 기록은 성과뿐 아니라 질문·실패·중단 이유도 포함한다.
- 공개, 상업화, 협업 확대는 각 실험에서 별도로 결정한다.

## 아직 정하지 않은 것
최종 슬로건, 시각 정체성, 대상 고객, 수익 모델, 공개 정책, 활동 주기는 미확정이다.
이 문서는 이전 대화에서 제공된 사용자 요구를 토대로 재구성한 초안이다.
이전 대화의 assistant 본문은 참조 표시만 제공되어 전체 내용을 검증하지 못했다.
