# AJAR 디자인 아이디어 이미지

2026-10-29 · 이미지 생성 도구로 제작한 탐색용 콘셉트

‘열려 있는 상태 자체’라는 브랜드 정의와 Warm paper / Deep moss / Open lime 팔레트를 바탕으로 세 가지 적용 방향을 탐색했다.

| 이미지 | 용도 | 살펴볼 점 |
| --- | --- | --- |
| `open-form.png` | 포스터·브랜드 그래픽 | 열린 윤곽, 입체감, 여백과 작은 라임 강조 |
| `paper-application.png` | 종이·노트 적용 아이디어 | 종이 질감, 겹침, 틈과 절제된 색 배치 |
| `mobile-application.png` | 모바일 비주얼 아이디어 | 가벼운 정보 위계, 간격, 구분선과 선택 상태 |

PNG는 생성 원본이며 WebP는 같은 이미지의 웹 표시용 사본이다. 생성 프롬프트와 사용 도구는 [prompts.md](prompts.md)에 기록한다.

이 이미지들은 디자인 방향을 살펴보기 위한 자료다. 실제 제작된 제품이나 구현된 앱 화면을 뜻하지 않는다. 생성 이미지 안의 추상 형태를 기준 로고로 사용하지 않는다. 공식 표기는 기존 C1 심볼과 Outfit Light 300 원본을 사용한다.
